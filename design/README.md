## Authoring tools

`design/.tools/` contains the stdio MCP client, original screen-authoring scripts, native-refinement and media tooling, and the screen verifier. These are design tooling, not portfolio application code. `verify_screens.py` checks the saved inspection JSON. Any regeneration must preserve the current native refinements and frame IDs; the original creation script alone does not represent the completed refinement workflow.
